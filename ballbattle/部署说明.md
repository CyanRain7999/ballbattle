# 球斗竞技场 · 部署说明

游戏是纯静态单文件，PWA（manifest + service worker）需要 **http(s) 环境**才能生效。
`file://` 双击打开永远可用，只是没有"安装到手机/离线缓存"功能。

---

## 方式一：本机玩（最简单，30 秒）

1. **双击 `start_server.bat`**（Windows）
2. 浏览器打开 **http://localhost:8080**
3. Chrome/Edge 地址栏右侧出现"安装"图标 → 点击即可像 App 一样使用（全屏、独立窗口）

> 原理：脚本用 Python 内置的 `python -m http.server 8080` 起服务，无需安装任何东西。

## 方式二：手机玩（同一 WiFi）

1. 电脑上双击 `start_server.bat`
2. 查看电脑局域网 IP：
   - 命令行输入 `ipconfig`，找"无线局域网适配器"下的 IPv4 地址（如 `192.168.1.5`）
3. 手机浏览器打开 **http://192.168.1.5:8080**
4. Android Chrome 可"添加到主屏幕"；iOS Safari 需 https 才显示该选项（见方式三）

## 方式三：部署到免费托管（推荐，手机/电脑都能装）

任选一个免费静态托管，把**整个文件夹**拖进去即可（index.html / manifest.webmanifest / sw.js / icons/ / start_server.bat 可不上传）：

| 平台 | 方法 | 说明 |
|---|---|---|
| **GitHub Pages** | 建仓库 → Settings → Pages → 选分支 | 免费 https，最稳定 |
| **Netlify** | netlify.com → "Deploy manually" → 拖文件夹 | 免费 https，拖拽即用，最快 |
| **Vercel** | vercel.com → 导入项目 | 免费 https |

部署后得到 `https://xxx.netlify.app` 之类的网址：
- 手机浏览器打开 → Android 添加到主屏幕 / iOS 分享 → 添加到主屏幕
- 全屏运行 + 离线可用（首次打开后断网也能玩）

---

## 常见问题

- **双击 index.html 还能玩吗？** 能，永远能。服务器方式只是额外开启 PWA 功能。
- **为什么手机提示安装不了？** iOS 要求 https；局域网 http 只能"添加到主屏幕"部分支持。用方式三的免费 https 托管即可。
- **改了游戏后手机缓存旧版？** service worker 会重新校验；也可在浏览器清除站点数据。
- **start_server.bat 闪退？** 确认已安装 Python（`python --version`）；没装就去 python.org 下载，或改用 `npx serve`（需要 Node）。
